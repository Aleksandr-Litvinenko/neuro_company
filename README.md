# neuro_company

Репозиторий-указатель. Рабочий код проекта живёт в
**[neuro_company_claude](https://github.com/Aleksandr-Litvinenko/neuro_company_claude)** —
идите туда.

---

## Что произошло

Имя `neuro_company` было занято под проект первым, но разработка сразу пошла
в соседнем репозитории `neuro_company_claude`, и этот остался пустым. Пустой
репозиторий без README и лицензии выглядит как брошенная заготовка, поэтому
здесь оставлен явный указатель: чтобы человек, пришедший по имени, за секунду
понял, куда идти, а не гадал, какой из двух живой.

## Что такое NEUROCORP

Нейрокомпания «из одного человека»: штат ИИ-агентов (два менеджера, руководитель
проектов и производственная команда), CRM и панель командного центра в реальном
времени.

Человек в этой схеме — **man-in-the-middle**: система ведёт десятки диалогов
параллельно, но каждое дорогое действие (исходящее сообщение, цена, смена стадии
сделки) агент **предлагает**, а не выполняет. На стол оператора приходит только
согласование Проекта и КП, остальное команда делает сама.

```
КЛИЕНТЫ → 2 МЕНЕДЖЕРА → РП → [ТЫ: согласуешь Проект+КП] → ПРОИЗВОДСТВО → СДАНО
                                                            │
            аналитик → разработчик / консультант → тестировщик → приёмщик
```

Стек: FastAPI, SQLite, WebSocket, панель на canvas. Запускается одной командой,
в демо-режиме внешние ключи не нужны.

## Судьба этого репозитория

Два варианта, оба нормальные:

1. **Оставить указателем** — как сейчас. Имя занято, ссылка ведёт куда надо.
2. **Сделать основным** — перенести код из `neuro_company_claude` сюда, а тот
   оставить указателем. Имя без суффикса `_claude` точнее описывает проект:
   он про нейрокомпанию, а не про инструмент, которым её собрали.

До принятия решения ничего не удаляется: удалённый репозиторий уносит с собой
историю и все внешние ссылки на него.
